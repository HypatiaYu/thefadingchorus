# The Fading Chorus

Run `npm start` with Node.js 18 or newer, then open http://127.0.0.1:3000.

Play with D, F, J, K, lane taps, or swipes. Space pauses. Mix controls adjust whales, drums, piano, and harmony.

All six whale and ten piano samples are embedded in index.html. The game also runs offline when that file is opened directly.

The updates form uses the local server. Signups are saved in .data/subscribers.json, with duplicate addresses combined. This is a local signup collection service.
